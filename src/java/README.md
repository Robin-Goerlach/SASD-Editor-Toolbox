# Java implementation lane

This directory is reserved for the Java implementation of SASD Editor Toolbox.

Status: **scaffold only**. No Java editor code is claimed yet.

When implementation begins, treat `../../spec/editor-v1.md` as the portable behavior contract, consume shared cases from `../../conformance/` through a Java test adapter, keep the reusable core UI-agnostic, use idiomatic Java packages/collections/concurrency rather than mirroring C# object layout, contain the Java build system inside this lane, and keep Java independent from the .NET and C++ binaries.

See `../../docs/en/MULTI-LANGUAGE-DEVELOPMENT.md`.
